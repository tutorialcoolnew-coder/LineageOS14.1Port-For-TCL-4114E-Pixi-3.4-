# LineageOS 14.1 Port-For-TCL-4114E-Pixi-3.4

The original project was created by the developer “wakudev”.

For more information about the ROM used, please refer to the original Wakudev repository.
LINK: https://github.com/wakudev/LineageOS_Pixi_3_35

This ROM is for the TCL 4114E device, which has the same hardware as the Alcatel OneTouch Pixi 3.4.
(I downloaded the wakudev ROM to my PC and modified it locally.) This is my first time using GitHub.

Use the AI to make the ROM and TWRP compatible.  

# tested functions
* Wi-Fi 
* Bluetooth 
* Sound (except for the earpiece speaker)
* LCD Backlight
* Rotation 
* Mobile Networks (3G/2G)  
* Flashlight 
* Physical Navigation Buttons (Back, Home, and Options) 
* Offline Charging 

# Not Working Features: 

* FM Radio 
* (For some reason, my TCL doesn't have an earpiece speaker. I don't know if it's a factory defect or if it fell off at some point. I wasn't able to test that.)

# Requirements: 

* TWRP 3.2.3 
* Charge it to at least 50% (it usually takes a while)
